# aadikailash.in — Official Pilgrimage Portal (2026)

Official pilgrimage website for **Mount Adi Kailash (Chhota Kailash)** and **Mount Om Parvat** in the Kumaon Himalayas, Uttarakhand, in association with **Helloo Adventure**.

## 🏔️ Overview

- **Expedition Basecamps**: Dharchula, Jolingkong, Gunji, Nabi, Kathgodam
- **Yatra Packages**:
  - `package-complete-circuit.html` — Complete Sacred Circuit (7D/6N)
  - `package-essential.html` — Essential Dharchula Basecamp (5D/4N)
  - `package-helicopter.html` — VIP Helicopter Darshan (3D/2N)
  - `package-grand-kumaon.html` — Grand Kumaon & Panchachuli Expedition (8D/7N)
- **Sacred Guides**:
  - `adi-kailash.html` — Complete Mount Adi Kailash Guide & Parvati Sarovar
  - `om-parvat.html` — Miraculous Natural Snow ॐ Formation Guide
  - `faq.html` — Comprehensive 31+ Q&A Hub with Real-Time Search & Category Filters

## 🚀 Running Locally

No dependencies required! Uses native Node.js:

```bash
# Start local development server
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- Semantic HTML5 with structured JSON-LD Schema (TravelAgency)
- Vanilla CSS3 (Custom Spiritual Himalayan Orange & Forest Green Design System)
- Native JavaScript ES6
- Zero-dependency Node.js HTTP Server
